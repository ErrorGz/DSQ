## 使用说明

- 输入每分钟需求的物品数量，然后点击后面的蓝色按钮选择物品即可。
- 参考数据：传送带360/min 高速传送带720/min 极速传送带1800/min
- 分拣器参考数据：分拣器90/min 高速分拣器180/min 极速分拣器360/min 集装分拣器7200/min
- 物品左边可以进行操作：
  - 标注:可以对某个物品进行(改颜色)比如已经完成生产线的物品
  - 多配方:可以对某个物品进行同时多个配方的计算
  - 排除:可以对某个物品进行排除计算
- 采矿机默认按6个矿脉，大型采矿机默认按20个
- 喷涂机的加速与增产剂同样，所以可以直接使用增产剂来进行设置。
- 临界光子、原油效率、分馏塔、轨道采集、运输站集装物流、大型采矿机 可从【参数设置】中配置
- 增产剂暂时只支持喷涂总量统计，不支持增产剂使用数量统计
- 关于蓝图生成，配置项移到了页面顶部的参数设置中，目前只支持通过(位面)熔炉、制造台、精炼厂、对撞机、（量子）化工厂、研究站六类生产设施进行制造的物品
- 【指定传送带】同时决定两件事：生成蓝图时每条带的运力上限，以及实际摆放的传送带类型。选低速传送带会让蓝图出现更多条并行的带（只有原料可以堆叠，按【传送带物品堆叠层数】计算）。
- 【指定分拣器】决定单个分拣器的承载上限以及实际摆放的类型。某个建筑的需求超过单个分拣器上限时，会拆成多个同类型分拣器；若该建筑的分拣器槽位不够，会自动升到更高一档并弹提示。
- 传送带与分拣器的上限互相独立，不互相压制。例如选集装分拣器配低速传送带时，分拣器不会因为带宽而降档，但该处传送带会成为瓶颈。
- 喷涂剂走线同样使用【指定传送带】所选的档位。

## 已知问题（待大佬修复）

- 高速传送带、高速分拣器、集装分拣器的建筑 `modelIndex` 取自早期被注释掉的代码，仓库内没有可交叉验证的数据源，**尚未在游戏内确认**。若导入蓝图后这几档显示成了别的建筑，请提 Issue 反馈。
- 【指定传送带】选低速档 + 【指定分拣器】选高速档时，建筑的分拣器槽位可能不够用。此时该处传送带会超载运行、产量低于预期（生成时会弹提示），提高传送带档位即可解决。
- 拆分后一台熔炉可能挂 4~6 个分拣器，位移逻辑已改为「每多一个分拣器扩展一格」，但高负载下与相邻建筑的实际碰撞情况尚未在游戏内验证。
- `calculateBuildingArea` 的熔炉留白按「物品种数 ≤ 2」估算，拆分后 2 种物品也可能需要 4 个分拣器，极端情况下留给熔炉的宽度可能不够。
